# ABD Movies — releases

Download the latest Windows installer from **[Releases](https://github.com/edfwasd1234/abd-movies-releases/releases/latest)**
(`ABD-Movies_<version>_x64-setup.exe`).

ABD Movies checks this page for updates. When a newer version is published here, the app tells you
your version is outdated and links straight to the new installer.

This repository only hosts release files; it contains no source code.
